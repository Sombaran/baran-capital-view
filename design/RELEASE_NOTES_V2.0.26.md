# Release Notes v2.0.26

**Version:** 2.0.26

## UI optimization

- The dashboard tab bar now uses balanced responsive rows instead of allowing a long tab label to sit alone on a second row.
- Desktop uses six stable columns; mobile uses two columns.
- Tab buttons have stable minimum heights, centered labels, and wrapped text for long names.
- Existing keyboard navigation, active-state styling, refresh behavior, and authenticated API routes remain unchanged.
- The post-login release popup now summarizes the navigation improvement alongside the new dashboard tabs.

No additional Stock API credentials or browser-exposed endpoints were added.
