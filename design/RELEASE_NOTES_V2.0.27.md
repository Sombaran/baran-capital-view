# Release Notes v2.0.27

**Version:** 2.0.27

## UI optimization

- Replaced the oversized equal-width tab grid with a compact horizontal navigation on desktop.
- Desktop tabs stay on one row with horizontal overflow when needed.
- Mobile switches to a balanced two-column layout.
- Long labels such as `Summary Dashboard` and `Global market news` remain readable without creating an isolated second row.
- Existing tab routing, keyboard behavior, refresh logic, authenticated API calls, and security boundaries remain unchanged.
- The login release popup continues to summarize the dashboard improvements.
